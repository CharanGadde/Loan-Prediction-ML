# Loan-Prediction-ML
Machine Learning project comparing Decision Tree, Random Forest, and Logistic Regression for loan prediction.
# Loan Prediction API

Predicts whether a customer requires a loan or not using machine learning.

## Features
- Single Prediction Endpoint (`/predict`)
- Batch Prediction Endpoint (`/predict/batch`)
- Built using FastAPI, Decision Tree Classifier, and Swagger UI

## Project Structure
- `01_Train_Model`: Scripts for training the machine learning model.
- `02_API_Server`: FastAPI server configuration and endpoints.
- `03_Test_API`: Scripts for testing the API endpoints.
